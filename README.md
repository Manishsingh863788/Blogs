# 🏛️ Home Drops Villa — Global Land Laws & Property Acts

An interactive, responsive full-stack web portal dedicated to exploring and analyzing property acts, real estate legal frameworks, and land regulations globally across countries, states, and cities.

🌐 **Live Demo:** [https://blogs-gamma-gray.vercel.app](https://blogs-gamma-gray.vercel.app)

---

## ✨ Features

- 🗺️ **Interactive World Map**: Visual exploration of land laws and regulations powered by Leaflet.
- 📂 **Multi-Level Law Exploration**: Easily navigate laws categorized by **Country**, **State**, and **City** levels.
- 📱 **Fully Responsive Design**: Optimized navigation with full horizontal menus on desktop/laptop and an intuitive 3-dot dropdown menu on mobile devices.
- 🔖 **Saved Articles & Bookmarking**: Save and reference important legal articles on demand.
- 🔍 **Search & Category Filters**: Quickly find laws by location, keyword, or legal category.
- 🛡️ **Admin Portal**: Secure management panel for drafting, featuring, and maintaining property law entries.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite, Lucide Icons, React Leaflet
- **Styling**: Modern CSS with Glassmorphism and Responsive Media Queries
- **Backend / Database**: Express / Node.js & SQLite / LibSQL
- **Deployment**: Vercel

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Manishsingh863788/Blogs.git
cd Blogs
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
